# references

**デザインや構成を決めるときに参考にしたものを残す場所。** 元の記事が消えても後から辿れるように、リンクだけでなく「そこから何を採るのか」まで書く。

## 何を置くか

- 参考にした記事・ドキュメント・リポジトリ
- デザインの参考にした画面・サービス
- 比較検討したライブラリの調査メモ

**決定そのものは置かない。** 何を採ってなぜそうしたかは [design-docs/](../design-docs/README.md) に書く。ここに置くのは、その判断の材料。

## ファイル名

リポジトリ共通の規約に従い、書いた日を prefix にする。

```text
<YYYYMMDD>_<topic>.md
```

例: `20260826_table-ui-references.md`

## 書き方

- 1 テーマ = 1 ファイル
- **URL だけ貼らない。** 何を見て、どこを採るのかを 1 行添える。リンクが切れたとき残るのはその 1 行だけ
- 参考にしなかったものも、見て外したなら理由ごと残す。同じものを二度調べなくて済む

# D1 を作る

新しい D1 は、デプロイの前に手で作る。場所を選べるのは、作るときだけだから。

## なぜ手で作るか

`wrangler.jsonc` の `d1_databases` に場所の項目は無く、`database_id` を省いてデプロイに作らせると場所を選べない。別のアプリでは、デプロイで作られた台帳が米国に置かれ、読み書きの往復のたびに余計に待たされていた。

場所を変える手順は公式に載っていない。移すには、作り直してデータを写すことになる。

## 手順

作る。

```sh
pnpm -F app exec wrangler d1 create <名前> --location apac
```

場所を確かめる。`running_in_region` が `APAC` になっていればよい。

```sh
pnpm -F app exec wrangler d1 info <名前>
```

**`--location` は希望の指定で、保証はされない。** `apac` はアジア太平洋を指す値で、日本だけを指定する値は無い。別のアプリでは、大阪に置かれたものとソウルに置かれたものがあった。

出力された `database_name` と `database_id` を、`apps/app/wrangler.jsonc` と `apps/admin/wrangler.jsonc` の `d1_databases` に書く。両アプリで同じ値を指す。
